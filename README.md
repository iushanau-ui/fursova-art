# Сайт-магазин художницы

Полностью статический сайт: HTML + CSS + JavaScript, без сборки, без бэкенда, без баз данных.
Это значит — **хостинг бесплатный навсегда**, ничего арендовать не нужно.

## Как посмотреть локально

Просто откройте `index.html` двойным кликом в браузере. Всё работает сразу.

## Как всё устроено

```
art-site/
├── index.html        — страница сайта (структура)
├── css/style.css     — оформление (цвета, шрифты)
├── js/products.js    — ⭐ ГЛАВНЫЙ ФАЙЛ: контакты, категории, каталог товаров
├── js/app.js         — логика (галерея, корзина) — трогать не нужно
└── images/           — фотографии работ
```

### Языки и валюты

Сайт трёхъязычный: **английский (по умолчанию), русский, итальянский** —
переключатель в шапке, выбор запоминается в браузере посетителя.
Все тексты задаются сразу на трёх языках в `js/products.js` в виде
`{ en: "...", ru: "...", it: "..." }`.

Цены задаются **один раз в евро** (`priceEUR`) — доллары и белорусские рубли
пересчитываются автоматически по курсам из блока `currencies` в `CONFIG`.
Курсы обновляйте вручную время от времени (поле `rate` — сколько единиц
валюты в 1 евро).

### Поменять имя, контакты, описание

Откройте `js/products.js` в любом текстовом редакторе (например, «Блокнот») —
в самом верху блок `CONFIG`. Впишите настоящие имя, Telegram, почту, Instagram, город.

### Добавить / изменить товар

В том же `js/products.js` в списке `PRODUCTS` скопируйте любой блок `{ ... },`
и поменяйте название, цену, размер, описание и путь к фото.

- Фото положите в папку `images/` (лучше JPG до ~500 КБ, вертикальные 4:5).
- `unique: true` — работа в единственном экземпляре (картина): бейдж «1 of 1»,
  в корзину кладётся максимум одна штука, без кнопок «+/−».
- Продана работа → поставьте `sold: true` — она останется в галерее с пометкой «Продано».
- Удалить товар → просто удалите его блок.

### Добавить новый раздел (будущее портфолио)

В `js/products.js` в списке `CATEGORIES` допишите строку, например:

```js
{ id: "ceramics", label: "Керамика" },
```

и указывайте `category: "ceramics"` у нужных товаров. Кнопка-фильтр появится сама.

## Как работает продажа (без сервера)

Покупатель складывает работы в корзину и жмёт «Отправить заказ» —
текст заказа (список работ, сумма, имя, контакт) копируется и открывается
ваш Telegram, либо формируется письмо на почту. Оплату и доставку вы
обсуждаете лично — как в Instagram-продажах, только с витриной и корзиной.

## Как выложить в интернет бесплатно

### Вариант 1 — GitHub Pages (рекомендую)

1. Зарегистрируйтесь на [github.com](https://github.com).
2. Создайте репозиторий (кнопка **New**), имя любое, например `art-shop`, тип Public.
3. На странице репозитория: **Add file → Upload files** — перетащите ВСЁ содержимое
   папки `art-site` (не саму папку, а файлы и подпапки внутри неё). Нажмите **Commit changes**.
4. Зайдите в **Settings → Pages**, в разделе «Build and deployment»
   выберите Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://ваш-ник.github.io/art-shop/`.

Обновление сайта = загрузить изменённые файлы тем же способом (Upload files → Commit).

### Вариант 2 — Cloudflare Pages

1. Зарегистрируйтесь на [pages.cloudflare.com](https://pages.cloudflare.com).
2. Create a project → **Direct Upload** → перетащите папку с сайтом.
3. Получите адрес вида `https://имя-проекта.pages.dev`. Лимитов для такого сайта нет.

### Свой домен (необязательно)

Красивый адрес вида `annaivanova.by` — это единственное, что стоит денег
(~10–30 BYN в год). И GitHub Pages, и Cloudflare Pages позволяют бесплатно
подключить свой домен в настройках. Без него сайт тоже полноценно работает.

## Советы по фотографиям

- Снимайте работы при дневном рассеянном свете, строго фронтально.
- Обрезайте по краям холста, выравнивайте горизонталь.
- Сжимайте перед загрузкой (например, на [squoosh.app](https://squoosh.app) — бесплатно),
  иначе сайт будет медленно открываться с телефона.
